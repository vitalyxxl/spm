1. Назначение устройства

Smart PowerMeter — модуль на DIN-рейку (35 мм) для измерения параметров электросети и передачи данных системе управления нагрузкой (DLB).

Устройство:

  • Измеряет напряжение, ток, мощность, накопленную энергию
  • Показывает показания на встроенном цветном дисплее
  • Передаёт данные по радиоканалу (HC-12 433 МГц или Wi-Fi ESP-NOW)
  • Ведёт веб-панель для просмотра и настройки
  • Поддерживает интеграцию с Home Assistant через MQTT
  • Подаёт аварийный сигнал при перегрузке
⚠️ Важно
Устройство не отключает нагрузку само — оно передаёт лимит и аварию внешнему устройству (EVSE), которое ограничивает ток.

2. Комплект поставки

  • Модуль Smart PowerMeter
  • Датчик тока (поставляется в комплекте, уже откалиброван под конкретный экземпляр устройства)
  • Паспорт / краткая памятка
✅ Преимущество
Датчик тока поставляется вместе с прибором и откалиброван на заводе под конкретный экземпляр. Дополнительная калибровка не требуется — показания готовы к использованию «из коробки».

3. Установка в щиток

⚠️ Внимание
Монтаж выполняет квалифицированный электрик. Перед работами — обесточить щит!

3.1. Крепление

Закрепите модуль на DIN-рейке 35 мм.

3.2. Подключение

Устройство имеет два винтовых клеммника:

КлеммникРасположениеЧто подключается
Датчик токаслеваДатчик тока из комплекта
Питание 220 ВсправаФаза (L), ноль (N)

Подключите датчик тока в левый клеммник согласно маркировке. Подайте питание 220 В на правый клеммник (L, N).

3.3. Первое включение

После подачи питания на дисплее: логотип → IP-адрес и показания. Если дисплей не загорелся — см. раздел 11.

4. Первое подключение

При первом включении (или если роутер недоступен > 1 минуты) устройство создаёт точку доступа Wi-Fi:

  • Имя сети: SmartPowerMeter
  • Адрес для входа: http://192.168.4.1 или http://spm.local

Шаги

  1. На смартфоне/ПК откройте список Wi-Fi, подключитесь к SmartPowerMeter.
  2. Откройте браузер, введите 192.168.4.1 (или spm.local).
  3. Появится окно входа:
    • Логин: admin
    • Пароль: 12345678
  4. Нажмите кнопку ⚙️ (настройки) в правом верхнем углу.
  5. Вкладка 🔵 Wi-Fi → выберите свою домашнюю сеть (нажмите круглую кнопку 🔄 для сканирования) → введите пароль → «Записать и перезагрузить».
  6. Устройство перезагрузится и подключится к вашему роутеру.
  7. Узнать новый адрес можно:
    • на дисплее устройства (IP показан в шапке)
    • по имени http://spm.local
    • через роутер (список клиентов)
💡 Совет
При повторной настройке пароль из памяти устройства подставляется автоматически — сетей запоминается до 5.

5. Главный экран

5.1. Плитки показаний

ПлиткаЧто показываетЦвет
НапряжениеВольты (В)🟡 жёлтый
Ток сетиАмперы (А)🟣 фиолетовый
Текущая мощностьВатты (Вт)🔵 голубой
Потреблённая энергиякВт·ч🟢 зелёный

5.2. Ряд EVSE (только при активной зарядке)

ПлиткаЧто показывает
Ток EVSE (Зарядка)Текущий ток зарядки (А)
Максимальный ток сетиЛимит линии DLB (А)

Ряд появляется автоматически, когда EVSE передаёт ток > 0, и скрывается через 15 секунд после пропадания связи.

5.3. График

Три линии:

  • 🟡 Вольт — напряжение
  • 🟣 Ток сети — общий ток
  • 🔵 Ток EVSE (пунктир) — ток зарядки

5.4. Индикаторы в шапке

Wi-Fi:

  • Палочки ▂▄▆█ — подключено к роутеру (уровень сигнала)
  • Круг с числом — режим точки доступа (сколько устройств подключено)
  • ❌ — нет подключения

Радиоканал (точка / квадрат — зависит от транспорта):

  • 🟢/🔵 мигает — идёт обмен с EVSE
  • ⚫ серый — нет обмена
  • Клик по индикатору → статистика канала (TX, RX, потери, %)

Кнопки в шапке:

  • ☀/🌙 — переключение темы (тёмная/светлая)
  • ⚙️ — открыть настройки

6. Настройки

Нажмите ⚙️ — откроется меню из 6 вкладок.

6.1. Wi-Fi

  • Выпадающий список — нажмите, чтобы раскрыть
  • 🔄 (кнопка справа) — сканировать сети
  • ✓ рядом с сетью — пароль уже сохранён в памяти устройства
  • (Текущая) — ваша активная сеть
  • Пароль — введите (если меняете); если сеть сохранена, подставится сам
  • «Записать и перезагрузить» — активна, только когда что-то изменено
💡 Совет
Сети сохраняются в архив (до 5). При смене роутера вернуться к старой сети можно без повторного ввода пароля.

6.2. Экран

  • Яркость — 0…255 (0 — выключить подсветку)
  • Ориентация:
    • Книжная (0°)
    • Альбомная (90°)
    • Перевернутая (180°)
    • Альбомная инв (270°)
  • «Применить настройки»

6.3. RF / ESP-NOW

  • Транспорт:
    • HC-12 — радио 433 МГц
    • ESP-NOW — Wi-Fi 2.4 ГГц
  • MAC-адрес EVSE — только для ESP-NOW, формат AA:BB:CC:DD:EE:FF
  • ID устройства — номер в сети DLB (1…N)
  • Интервал отправки — период в секундах
  • Рабочий канал — 1…100 (только HC-12)
  • Мощность передатчика:
    • P1 — мин. (-1 dBm)
    • P2 (-2 dBm)
    • P3 (2 dBm)
    • P4 (5 dBm)
    • P5 (8 dBm)
    • P6 (11 dBm)
    • P7 (14 dBm)
    • P8 — макс. (20 dBm)
  • Режим работы (FU):
    • FU1 — 9600 бод
    • FU2 — 9600 бод
    • FU3 — 9600 бод (по умолчанию)
    • FU4 — 1200 бод, дальнобойный
  • «Сохранить параметры RF» → перезагрузка
⚠️ Транспорт должен совпадать
Если на SPM выбран HC-12, а на EVSE — ESP-NOW (или наоборот), связи не будет.
⚠️ «Радиомодуль не обнаружен»
Проверьте подключение HC-12 или переключитесь на ESP-NOW.

6.4. MQTT (Home Assistant)

  • Включить MQTT — галочка
  • IP-адрес брокера — например, адрес вашего Home Assistant
  • Порт — по умолчанию 1883
  • Логин / Пароль — если требует брокер
  • Автообнаружение (Discovery) — галочка
  • «📡 Применить настройки MQTT» → перезагрузка

6.5. Пароли

  • Логин администратора — по умолчанию admin
  • Новый пароль — оставьте пустым, если не меняете
  • «Обновить пароль»
⚠️ Опасная зона
«Сбросить счётчик кВт·ч» — обнуляет накопленную энергию. Спросит подтверждение. Отменить нельзя.

6.6. Инфо

Техническая информация:

  • Время работы (дни.часы.минуты.секунды)
  • Причина последней перезагрузки (зелёный — норма, красный — сбой)
  • Тип чипа, частота, ID, MAC
  • Свободная память (Heap)
  • Занято LittleFS
  • 🔄 «Обновить статус»

7. Авария перегрузки

При срабатывании защиты:

  • Фон страницы становится красным
  • Заголовок: «ВНИМАНИЕ: ПЕРЕГРУЗКА!»
  • Индикатор Wi-Fi меняет цвет на жёлтый
  • На дисплее — красный фон
  • Устройство отправляет SOS-пакет EVSE (если транспорт подключён)

Авария снимается автоматически, когда перегрузка исчезает.

8. Home Assistant (MQTT)

После включения MQTT и Discovery в Home Assistant автоматически появятся сенсоры устройства Smart PowerMeter:

  • Напряжение SPM (В)
  • Ток SPM (А)
  • Мощность SPM (Вт)
  • Энергия SPM (кВт·ч)
  • Ток EVSE (А)
  • Лимит линии (А)

Данные обновляются каждые 5 секунд.

Топики (для продвинутых):

  • spm/telemetry — JSON с показаниями
  • spm/status — online
  • homeassistant/sensor/spm_*/config — discovery
ℹ️ Примечание
Управлять SPM из Home Assistant нельзя — только читать данные.

9. Обновление прошивки (OTA)

Доступно в скрытом сервисном меню:

  1. Кликните 3 раза по индикатору Wi-Fi (палочки/круг в шапке).
  2. Введите FactoryPassword (заводской ключ) → «Подтвердить».
  3. Откроется окно с 3 вкладками.

9.1. Вкладка «🔄 Обновление ПО»

  • Показаны текущие версии: SW (прошивка) и UI (интерфейс)
  • «Начать обновление из облака» — скачает и установит обе части с GitHub (если есть бейдж NEW — доступна новая версия)
  • Или локальный файл — выберите .bin вручную:
    • firmware.bin — прошивка
    • littlefs.bin — веб-интерфейс
  • Прогресс-бары показывают: Общий прогресс и Загрузка текущего блока
  • «Начать обновление из файлов»
⚠️ Не отключайте питание
Во время прошивки на дисплее идёт отсчёт процентов. После завершения — автоматическая перезагрузка и возврат на главную через 5–6 секунд.

9.2. Вкладка «🎛 Калибровка BL0942»

⚠️ Только для специалиста
Калибровка уже выполнена на заводе. Не изменяйте коэффициенты без эталонного прибора.
  • Поправка Напряжения — коэффициент (по умолчанию 1.0000)
  • Поправка Тока — коэффициент
  • «Сохранить калибровки»

Применяется сразу, без перезагрузки. Показания на главной обновятся.

9.3. Вкладка «📝 Системный лог»

  • 🔄 Обновить — загрузить лог с устройства
  • 🗑 Очистить — стереть лог
  • Текстовое поле — журнал событий (до 64 КБ)
  • Автоскролл к последним событиям

Полезно для диагностики: ошибки Wi-Fi, MQTT, радиоканала.

10. Индикаторы на дисплее устройства

10.1. Шапка дисплея

  • Палочки Wi-Fi — уровень сигнала (4 шт = максимум)
  • ❌ — нет подключения к Wi-Fi
  • IP-адрес в синей рамке
  • Точка (HC-12) / Квадрат (ESP-NOW):
    • 🟢 зелёный — передача пакета
    • 🔵 синий — приём эха от EVSE
    • ⚫ серый — нет обмена

10.2. Основные поля

  • Напряжение — жёлтым, крупно
  • Ток — фиолетовым; если есть лимит — формат ток/лимитА
  • Мощность — белым, W
  • Энергия — белым, kWh
  • Блок EVSE (синий, слева внизу):
    • Активен: верхнее число — ток EVSE (А), нижнее (розовое) — лимит линии (А)
    • Не активен: надпись «EVSE»

10.3. Авария

  • Весь экран — красный фон
  • Название «ВНИМАНИЕ: ПЕРЕГРУЗКА!» в вебе

12. Меры безопасности

⚠️ Обязательно к прочтению
  • Монтаж выполняет квалифицированный электрик
  • Не вскрывайте корпус под напряжением — внутри 220 В
  • Не превышайте номинальные параметры устройства и датчика тока
  • Перед работами — обесточить щит
  • Не закрывайте вентиляционные отверстия (если есть)
  • Не допускайте попадания влаги
